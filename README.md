- Grounded responses in retail policy documentation using semantic RAG with **PostgreSQL pgvector**.
- Engineered real-time WebSocket communication and automated escalation triggers (negative sentiment, query failure) to route chats to human support agents seamlessly.

#### 3. [English Coach — Adaptive AI Language Learning Platform](https://github.com/Z-Dev-Coder/english-coach)

- Engineered a conversational **Speaking Script Studio** providing structured cadence and dialogue practice.
